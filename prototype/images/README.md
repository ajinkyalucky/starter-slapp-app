# Prototype images

The HTML loads PNGs from this folder. Until a `<name>.png` exists, the page falls back to the `<name>.svg` placeholder I generated.

## Expected filenames

Body types — 2:3 portrait crops work best (e.g. 600×900):
- `slim.png`
- `athletic.png`
- `heavyset.png`
- `muscular.png`

Brand logos — transparent background ideal:
- `hm.png`
- `zara.png`
- `uniqlo.png`
- `levis.png`

## Template zip

`../images-template.zip` (one level up) bundles all 8 placeholder PNGs at the right sizes/aspects. Download → swap each file's content with your render → re-upload with the same names.
