# DRIP — clickable prototype

Click-through prototype of the 17 onboarding screens (splash → chat).

## Run it

Just open `prototype/index.html` in a browser, or serve the directory:

```
cd prototype
python3 -m http.server 8000
# → http://localhost:8000
```

## How to navigate

- Tap any **primary button** in the device frame to advance.
- Use the **left sidebar** to jump to any screen.
- **Prev / Next** buttons or **← →** arrow keys also work.
